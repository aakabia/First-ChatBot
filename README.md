## Description

Pocket Therapist is an AI-driven chatbot designed to offer personalized therapeutic support through engaging conversations. The backend is built using Botkit and Botbuilder to handle natural language processing and dialogue management, ensuring smooth and intuitive interactions. WebSocket enables real-time communication between the client and server, while MongoDB provides a reliable database for securely storing user data and session history. dotenv is used for managing sensitive configuration details, like API keys, securely in the environment.

On the frontend, React powers a dynamic, interactive user interface, with Bootstrap ensuring the design is responsive and user-friendly across devices. WebSocket also enables real-time updates on the frontend, creating seamless interactions between the user and the chatbot, regardless of platform.

## Installation

To install this application, start by cloning the code from my GitHub repository. Once cloned, run npm i in your terminal to install all the required packages. After that, create a .env file in the server folder and populate it with the necessary environment variables. These variables include your MongoDB connection string and your OpenAI API key, which are essential for the application to function properly.

## Usage

To use this application, run npm start in the root directory. Then, visit http://localhost:3001 in your browser to start interacting with the chatbot.
